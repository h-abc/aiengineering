# 📊 聊天记录分析器

上传微信聊天记录，自动分析话题和情绪趋势。**纯前端实现，数据不上传，无需 API Key，无需安装任何软件。**

## 功能

- 📁 **上传微信聊天记录**：支持 `.txt` 导出文件，多种日期格式
- 💬 **话题分析**：基于话题词典自动识别 8 类话题（版本发布、测试、需求讨论、技术讨论、时间协调、团队沟通、问题排查、学习分享）
- 😊 **情绪趋势**：基于情感词典分析每日情绪变化，正面/中性/负面占比
- 📅 **活跃度**：按小时和按天统计消息分布
- 📝 **消息列表**：按发送者筛选 + 关键词搜索 + 情绪标签

## 快速开始

### 在线使用

打开 `https://h-abc.github.io/aiengineering/`

上传微信 `.txt` 文件即可。

### 本地使用

1. 下载 `index.html`
2. 双击在浏览器中打开
3. 上传微信 `.txt` 文件

## 如何导出微信聊天记录

1. 打开手机微信
2. 进入聊天 → 右上角 ··· → 查找聊天记录
3. 选择消息 → 发送到电脑
4. 保存为 `.txt` 文件

## 安全说明

| 特性 | 说明 |
|---|---|
| 数据上传 | ❌ 不上传，所有数据在浏览器本地处理 |
| API Key | ❌ 不需要，纯规则化分析 |
| 隐私 | ✅ 聊天记录不会离开你的电脑 |
| 存储 | ✅ 无后端数据库，无持久化存储 |

## 已知限制

| 限制 | 说明 |
|---|---|
| 仅支持微信 `.txt` | 不支持 Telegram/Slack/Discord |
| 情感词典有限 | 40+ 正面词 + 40+ 负面词，可能漏判 |
| 话题词典有限 | 8 类话题，可能无法覆盖所有场景 |
| 单文件 | 无多文件上传 |
